## Linux CS2 Dumper (Beta)

![Dump](https://github.com/islavikfx/Linux-CS2-Dumper/blob/main/photo/screenshot.png?raw=true)

Platform: Linux only.

Execute: Download run.sh from the repository and run it with sudo.
```bash
sudo sh run.sh
```

The generated dump will be saved at ~/Linux-CS2-Dumper/output/libclient_dump(x).cs.

The dumper is currently in the pre-release and it dumping only main code from libclient.so. If you encounter any bugs or have suggestions for improvement - open an issue on GitHub.

### Features:

 [+] Structured memory dumping by analyzing schemas from libclient.so.

 [+] Extracts main classes/fields with their types and offsets.

 [+] Generates clean C# dump with offsets.
